FHE16 is waLLLnut's low-latency confidential computation engine. This documentation is organized around three tracks:

- **A. FHE16 paper reviews**: explain each paper and how it supports the engine.
- **B. Products**: show how FHE16 becomes blockchain, auction, risk, and other confidential workflows.
- **C. FHE16 API**: define one shared method surface across Web Browser, C, Rust, and Python bindings.

## Current Status

This documentation is the working source tree for FHE16 technical docs. It is written in MDX so the paper reviews, product pages, and SDK references can stay structured as the platform grows.

The API pages are a design draft. They describe the shared language-binding surface we plan to expose; they are not a production availability statement.

## Documentation Goals

- Explain each core paper in product-facing technical language.
- Connect papers to product surfaces such as blockchain, auction, and risk workflows.
- Define a stable FFI-first API vocabulary before SDKs and partner integrations harden.
- Keep public links stable as FHE16 grows into a developer platform.
