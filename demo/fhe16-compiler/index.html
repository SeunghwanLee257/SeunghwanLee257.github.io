함수

분기 — 갈라진 상태를 하나로 합친다

암호문 조건은 어느 쪽이 참인지 볼 수 없다. 그래서 가지를 고르지 않는다. 양쪽을 다 계산한 뒤, 합류 지점에서 변수 하나마다 상태를 하나로 합친다. 컴파일러 용어로 SSA의 φ 노드이고, 암호문에서는 이 φ 를 산술로 만든다.

쓴 코드
let s = a;
if (a > b) {
  s = a * 2;
} else {
  s = b * 3;
}
→
합류된 상태
c = a > b
t = a * 2
e = b * 3
s = φ(c, t, e)
분기에서 바뀐 변수마다 합류가 하나씩 생긴다. 안 바뀐 변수는 합치지 않는다. 중첩된 if 는 안쪽부터 합쳐진다.

합류를 만드는 방법은 여러 가지다

삼항연산자 c ? t : e 는 합류를 적는 한 가지 표기일 뿐이다. 실제 회로는 모양을 보고 더 싼 쪽을 고른다.

합류 모양회로비용
φ(c, t, e) 일반형e + c·(t−e)뺄셈·곱셈·덧셈 3연산
φ(c, t, 0)c·t곱셈 1연산
φ(c, 0, e)(1−c)·e뺄셈·곱셈 2연산
φ(c, 1, 0)c연산 없음
φ(c, x, x)x합류 자체를 지운다
양쪽이 상수상수 접기암호문 연산 없음
대가는 양쪽 계산 비용을 둘 다 낸다는 것이다. 쓰지 않을 가지도 실제로 돈다. 분기가 깊어질수록 비용이 곱으로 늘어나므로, 깊은 분기보다 산술식이 유리하다.
