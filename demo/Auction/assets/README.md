# Demo product imagery

Four original fictional collectible concepts generated for the waLLLnut auction storefront on 2026-09-15:

- `blue.webp` — Moon Explorer / Blue Hour
- `cream.webp` — Little Pebble / Warm Ivory
- `coral.webp` — Sunday Sprout / Soft Coral
- `moss.webp` — Moss Companion / Sage Green

Created with the built-in image generation tool as studio product renders, then encoded as WebP.
These are demonstration visuals, not photographs of real inventory or partner artists' products.
Reference stores informed the page layout; their product photos and branding are not included.
