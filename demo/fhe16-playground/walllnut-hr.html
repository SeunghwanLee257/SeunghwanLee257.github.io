Demo vs. Production데모와 실제 운영의 경계

This page simulates the server role inside a single browser worker. In production, the server runs as a separate process and the information below never leaves it.이 페이지는 하나의 브라우저 worker 안에서 서버 역할을 시뮬레이션합니다. 실제 운영에서는 서버가 별도 프로세스로 분리되고, 아래 정보는 서버 밖으로 나가지 않습니다.

Server-only information실제 운영에서 서버만 아는 정보
  • FHE secret key
  • Plaintext threshold, rule, weight평문 threshold, rule, weight
  • Policy compiler source & version-specific rule packpolicy compiler source와 버전별 rule pack
  • Decryption results & query budget/audit log복호화 결과와 query budget/audit log
What the browser receives브라우저가 받는 정보
  • public/evaluation key
  • encrypted policy blob
  • policy version & consent receiptpolicy version과 consent receipt
  • Final bit/bucket & server-signed receipt최종 bit/bucket과 서버 서명 영수증
Simplified in this demo현재 데모에서 단순화한 것
  • Server simulated as in-worker sandbox서버를 worker 내부 sandbox로 시뮬레이션
  • Predicate bit combination instead of integer comparisoninteger comparison 대신 predicate bit 조합 사용
  • Proof is a demo receipt; production uses server signatureproof는 데모 영수증이며 production에서는 서버 서명으로 대체
