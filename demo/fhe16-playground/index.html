FHE16 WASM

Gate & Arithmetic Playground

Run boolean gates, integer arithmetic, and floating-point operations on encrypted data — directly in your browser, powered by FHE16 WebAssembly.

UNSAFE demo artifact: the public builds intentionally use zero-error test parameters and provide no cryptographic security. Do not use sensitive data.

How It Works

Fully Homomorphic Encryption (FHE) lets you compute on encrypted integers and floats without ever decrypting them. In a secure production build, the compute party operates on ciphertexts without the plaintext inputs. This public demo is not such a security build and decrypts results locally for verification. Results are bit-exact to ordinary plaintext arithmetic.

  1. Load Module — select a build and click Load Module to fetch the WASM binary (~10 MB). Wait for "Module ready".
  2. Generate Keys — click Generate Keys to create the bootstrapping key set. This takes 10–30 seconds and only needs to be done once per session.
  3. Pick a tab — Boolean Gates for single-bit ops, Arithmetic for 32-bit integers, Float for IEEE-754 f32.
  4. Enter values and Run — inputs are encrypted on the fly, the operation runs over ciphertexts, and the decrypted result is shown alongside the expected plaintext value.

The Runtime Log below shows per-operation timings and any diagnostics.

Idle

Signed 32-bit FHE integer (−2,147,483,648 … 2,147,483,647). enc = encrypted input, imm = plaintext constant, k = plaintext shift amount.

Ciphertexts

FHE16 bit-decomposed IEEE-754 single-precision (f32) over encrypted values: arithmetic (+ − × ÷, min/max/copysign), unary (abs/neg/floor/ceil/round/trunc), and compares (< > ≤ ≥ = ≠ → 0/1). Bit-exact to CPU float.
