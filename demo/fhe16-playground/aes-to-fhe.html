AES Cloud Server → FHE Compute AES 클라우드 서버 → 동형암호 연산

Your cloud server already encrypts data with AES. Add the FHE16 evaluation key and the same server can compute on your data — without ever decrypting it. No infrastructure change. No new trust. 기존 클라우드 서버는 이미 AES로 데이터를 암호화합니다. FHE16 평가 키만 추가하면 같은 서버가 복호화 없이 데이터를 연산할 수 있습니다. 인프라 변경 없이, 신뢰 확장 없이.

Client → Cloud: Upload FHE evaluation key 클라이언트 → 클라우드: FHE 평가 키 업로드
Eval key enables computation — not decryption. Think of it as a "compute licence" for the cloud. 평가 키는 연산만 허용하며 복호화 불가. 클라우드의 "연산 라이선스"와 같음.

3
Cloud: AES → FHE transciphering + compute 클라우드: AES → FHE 트랜스사이퍼링 + 연산
Cloud converts AES ciphertext to FHE ciphertext (transciphering), then runs the FHE circuit. Result stays encrypted. AES 암호문을 FHE 암호문으로 변환(트랜스사이퍼링) 후 FHE 회로 실행. 결과는 여전히 암호화 상태.

4
Client: decrypt the FHE result 클라이언트: FHE 결과 복호화
Only the client (who holds the FHE secret key) can read the final answer. FHE 비밀키를 가진 클라이언트만 최종 결과를 읽을 수 있습니다.
