Offload ciphertext compute to an external pool; extend private circuits to the MPC family암호문 계산은 외부 pool에, private circuit은 MPC 계열로 확장

The baseline is FHE outsourcing. An external worker pool receives only ciphertext and a public/template circuit manifest — no secret key — and returns enc_result. When the circuit itself or both inputs need stronger hiding, extend to MPC, 2PC, PFE, or FHE+MPC hybrid. ZK correctness proofs are T.B.O — outsourced to external ZK stacks (RISC Zero, SP1, Halo2).기본형은 FHE outsourcing입니다. 외부 worker pool은 secret key 없이 ciphertext와 공개/템플릿 circuit manifest만 받아 enc_result를 계산합니다. 회로 자체나 양쪽 입력을 더 강하게 숨겨야 하면 MPC, 2PC, PFE 또는 FHE+MPC hybrid로 확장합니다. ZK correctness proof는 T.B.O — 외부 ZK 스택(RISC Zero, SP1, Halo2)에 위임합니다.

The boundary between FHE outsourcing and MPC hybridFHE outsourcing과 MPC hybrid의 경계

Using an external compute pool does not make something MPC. The protocol depends on what needs to be hidden.외부 compute pool을 쓴다고 전부 MPC는 아닙니다. 무엇을 숨기는지에 따라 프로토콜이 달라집니다.

FHE outsourcing

The external worker sees only ciphertext, evaluation key, and a public or template circuit. It never sees the SK or plaintext input/policy, and returns only enc_result. The live demo on this page is this case.외부 worker는 ciphertext, evaluation key, 공개 또는 템플릿 circuit만 봅니다. SK와 plaintext input/policy는 보지 못하고 enc_result만 반환합니다. 이 페이지의 실행 데모는 여기에 해당합니다.

MPC / 2PC / PFE

Required when the server's private circuit/function itself or both inputs need stronger hiding. The private circuit provider model is closer to this family than simple FHE outsourcing.서버의 private circuit/function 자체나 양쪽 입력을 더 강하게 숨겨야 할 때 필요합니다. private circuit provider 모델은 단순 FHE outsourcing보다 이 계열에 가깝습니다.

FHE + MPC hybrid

FHE handles ciphertext evaluation; MPC handles private circuit labels, threshold decryption, key custody, verifiable receipt, and parts of settlement. Cost increases but trust separation is stronger.FHE가 암호문 평가를 맡고, MPC는 private circuit labels, threshold decrypt, key custody, verifiable receipt, settlement 일부를 맡습니다. 비용은 늘지만 신뢰 분리가 강해집니다.

Production topology실제 운영 토폴로지

Blockchain is best used as a commitment/audit/settlement layer, not a compute engine. Heavy FHE computation is handled by an external compute pool or coprocessor; only the server holds the SK and plaintext policy. Note: this baseline is FHE outsourcing, not MPC.블록체인은 계산 엔진이 아니라 commitment/audit/settlement layer로 쓰는 편이 맞습니다. 무거운 FHE 연산은 외부 compute pool 또는 coprocessor가 수행하고, SK와 평문 policy는 서버만 보유합니다. 단, 이 baseline은 MPC가 아니라 FHE outsourcing입니다.

EDR encrypted job

Endpoint telemetry predicate bits and vendor rule circuit are delegated to an external compute pool. In the baseline the circuit template may be visible, but the node never sees the plaintext threshold of an alert rule or raw endpoint events. Hiding circuit topology requires MPC/PFE.Endpoint telemetry predicate bits와 vendor rule circuit을 외부 compute pool에 맡깁니다. baseline에서는 circuit template은 보일 수 있지만 node는 alert rule의 평문 threshold나 endpoint raw event를 보지 못합니다. circuit topology까지 숨기려면 MPC/PFE가 필요합니다.
