## Caller

Unsigned modulo by fixed plaintext divisor.

## Raw Symbols

- `FHE16_MOD_CONST`

## Circuit Path

Constant division, multiply quotient by divisor, then subtract.

## Output

Unsigned remainder ciphertext.

## Ownership

Returned ciphertext is caller-owned.

## C Example

```c
int32_t* out = FHE16_MOD_CONST(a, 10);
FHE16_Free(out);
```
