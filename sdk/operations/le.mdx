## Caller

Threshold filters and less-or-equal guard logic.

## Raw Symbols

- `FHE16_LE`

## Circuit Path

FHE16_GT followed by encrypted NOT.

## Output

1-bit boolean ciphertext.

## Ownership

Returned ciphertext is caller-owned.

## C Example

```c
int32_t* out = FHE16_LE(a, b);
FHE16_Free(out);
```
