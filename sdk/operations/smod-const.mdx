## Caller

Signed modulo by fixed plaintext divisor.

## Raw Symbols

- `FHE16_SMOD_CONST`

## Circuit Path

Signed quotient path plus multiply/subtract remainder path.

## Output

Signed remainder ciphertext.

## Ownership

Returned ciphertext is caller-owned.

## C Example

```c

FHE16_Free(out);
```
