## Caller

Fixed scaling and low-cost left shift workflows.

## Raw Symbols

- `FHE16_SHL`
- `FHE16_LSHIFTL`

## Circuit Path

Data copy plus encrypted zero fill for introduced lower bits.

## Output

Shifted ciphertext, usually wider than input.

## Ownership

Returned ciphertext is caller-owned.

## C Example

```c
int32_t* out = FHE16_SHL(a, 2);
FHE16_Free(out);
```
