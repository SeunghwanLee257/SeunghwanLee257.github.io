## Caller

Advanced signed modulo with encrypted divisor.

## Raw Symbols

- `FHE16_SMOD`

## Circuit Path

Signed division path returning signed remainder.

## Output

Signed remainder ciphertext.

## Ownership

Returned ciphertext is caller-owned.

## C Example

```c
int32_t* out = FHE16_SMOD(a, b);
FHE16_Free(out);
```
