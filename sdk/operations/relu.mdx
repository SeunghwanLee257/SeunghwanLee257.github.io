## Caller

Signed thresholding and ML-style activation flows.

## Raw Symbols

- `FHE16_RELU`

## Circuit Path

Sign-bit gated selection circuit: negative values map to encrypted zero, non-negative values pass through.

## Output

n-bit integer ciphertext.

## Ownership

Returned ciphertext is caller-owned.

## C Example

```c
int32_t* out = FHE16_RELU(a);
FHE16_Free(out);
```
