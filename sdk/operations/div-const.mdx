## Caller

Unsigned division by fixed plaintext divisor.

## Raw Symbols

- `FHE16_DIV_CONST`

## Circuit Path

Magic multiplier, constant multiply, then shift.

## Output

Unsigned quotient ciphertext.

## Ownership

Returned ciphertext is caller-owned.

## C Example

```c
int32_t* out = FHE16_DIV_CONST(a, 10);
FHE16_Free(out);
```
