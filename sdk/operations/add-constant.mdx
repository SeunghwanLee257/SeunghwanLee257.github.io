## Caller

Browser constants, SDK scalar arithmetic, fixed offset workflows.

## Raw Symbols

- `FHE16_ADD_CONSTANT_Arr`
- `FHE16_ADD_CONSTANT_I64`
- `FHE16_ADD_CONSTANT_I32`

## Circuit Path

Plaintext constant bits are folded into encrypted prefix-add path.

## Output

n-bit integer ciphertext.

## Ownership

Returned ciphertext is caller-owned.

## C Example

```c
int32_t* out = FHE16_ADD_CONSTANT_I32(a, 7);
FHE16_Free(out);
```
