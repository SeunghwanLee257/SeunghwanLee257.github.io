## Caller

Ternary conditionals and product workflows that choose between encrypted values.

## Raw Symbols

- `FHE16_SELECT`

## Circuit Path

SELECT circuit; selector can be one bit or same-width vector.

## Output

Ciphertext with selected encrypted value.

## Ownership

Returned ciphertext is caller-owned.

## C Example

```c
int32_t* out = FHE16_SELECT(selector, a, b);
FHE16_Free(out);
```
