## Caller

Advanced unsigned division with encrypted divisor.

## Raw Symbols

- `FHE16_UDIV`

## Circuit Path

Non-restoring division over encrypted operands.

## Output

Unsigned quotient ciphertext and optional remainder output.

## Ownership

Quotient and returned remainder are caller-owned.

## C Example

```c
int32_t* rem = NULL; int32_t* q = FHE16_UDIV(a, b, &rem);
FHE16_Free(out);
```
