## Caller

Advanced signed division with encrypted divisor.

## Raw Symbols

- `FHE16_SDIV`

## Circuit Path

Sign extraction, absolute-value division, sign correction, and optional zero flag.

## Output

Signed quotient, optional remainder, optional zero flag.

## Ownership

Each returned pointer is caller-owned.

## C Example

```c
int32_t* rem = NULL; int32_t* zero = NULL; int32_t* q = FHE16_SDIV(a, b, &rem, &zero);
FHE16_Free(out);
```
