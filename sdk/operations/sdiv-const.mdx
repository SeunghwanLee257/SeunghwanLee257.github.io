## Caller

Signed division by fixed plaintext divisor.

## Raw Symbols

- `FHE16_SDIV_CONST`

## Circuit Path

ABS, unsigned constant division, NEG, and SELECT by sign.

## Output

Signed quotient ciphertext.

## Ownership

Returned ciphertext is caller-owned.

## C Example

```c
int32_t* out = FHE16_SDIV_CONST(a, -10);
FHE16_Free(out);
```
