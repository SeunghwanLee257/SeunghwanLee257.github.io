## Caller

SDK arithmetic calls, product compute flows, benchmarks that need same-width encrypted addition.

## Raw Symbols

- `FHE16_ADD`

## Circuit Path

Parallel prefix adder through FHE16_PREFIX_Templete with subtract=false, executed by PrefixAdder_V2 worker threads.

## Output

n-bit integer ciphertext.

## Ownership

Returned ciphertext is caller-owned and must be released with FHE16_Free.

## C Example

```c
int32_t* out = FHE16_ADD(a, b);
FHE16_Free(out);
```
