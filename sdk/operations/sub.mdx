## Caller

SDK arithmetic calls and product compute flows that need encrypted subtraction.

## Raw Symbols

- `FHE16_SUB`

## Circuit Path

Parallel prefix adder through FHE16_PREFIX_Templete with subtract=true.

## Output

n-bit integer ciphertext.

## Ownership

Returned ciphertext is caller-owned.

## C Example

```c
int32_t* out = FHE16_SUB(a, b);
FHE16_Free(out);
```
