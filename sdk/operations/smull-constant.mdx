## Caller

Scoring weights, fixed coefficients, browser scalar multiply.

## Raw Symbols

- `FHE16_SMULL_CONSTANT_Arr`
- `FHE16_SMULL_CONSTANT_I64`
- `FHE16_SMULL_CONSTANT_I32`

## Circuit Path

NAF-aware shifted partial products plus DADDA reduction; zero and power-of-two constants use fast paths.

## Output

n-bit signed product ciphertext.

## Ownership

Returned ciphertext is caller-owned.

## C Example

```c
int32_t* out = FHE16_SMULL_CONSTANT_I32(a, 13);
FHE16_Free(out);
```
