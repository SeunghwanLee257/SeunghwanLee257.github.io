## Caller

Integer bitwise API and browser worker bitwise compute.

## Raw Symbols

- `FHE16_XORVEC`

## Circuit Path

FHE16_GATE_TEMPLETE with type=2 and GATE_VEC across encrypted bits.

## Output

Vector/integer ciphertext.

## Ownership

Returned ciphertext is caller-owned.

## C Example

```c
int32_t* out = FHE16_XORVEC(a, b);
FHE16_Free(out);
```
