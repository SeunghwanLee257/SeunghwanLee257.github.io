## Caller

Greater-or-equal guard logic and range checks.

## Raw Symbols

- `FHE16_GE`

## Circuit Path

FHE16_LT followed by encrypted NOT.

## Output

1-bit boolean ciphertext.

## Ownership

Returned ciphertext is caller-owned.

## C Example

```c

FHE16_Free(out);
```
