## Caller

Advanced unsigned modulo with encrypted divisor.

## Raw Symbols

- `FHE16_UMOD`

## Circuit Path

Variable unsigned division path returning remainder.

## Output

Unsigned remainder ciphertext.

## Ownership

Returned ciphertext is caller-owned.

## C Example

```c
int32_t* out = FHE16_UMOD(a, b);
FHE16_Free(out);
```
