The common method surface should be derived from `FHE16Ver6/include/soAPI/soAPI.hpp`. Language wrappers can use idiomatic names, but they should map directly to these raw operations so tests and benchmarks stay reusable.

<Warning>
  `FHE16_API.hpp` contains older double-underscore wrapper names. Use `soAPI.hpp` as the current public C ABI baseline unless the build target explicitly requires the older wrapper.
</Warning>

## Context and Keys

| Raw C symbol | Purpose | Public wrapper direction |
| --- | --- | --- |
| `FHE16_SetThreadCount` | Set worker thread count before initialization. | `ContextOptions.threads` or equivalent. |
| `FHE16_GetThreadCount` | Read current thread setting. | `ctx.thread_count()`. |
| `FHE16_GenEval` | Generate evaluation material and return runtime-owned secret key pointer. | `ctx.keygen()` returning an owned key reference. |
| `FHE16_LoadEval` | Load evaluation key material from files. | `ctx.load_eval_key(...)`. |
| `FHE16_SaveEval` | Save generated evaluation material. | Local/admin-only export. |
| `FHE16_MemoryAlloc` | Allocate runtime buffers before loading keys. | Hidden by wrapper initialization. |
| `FHE16_DeleteEval` | Release global evaluation resources. | `ctx.close()` / `Drop` / context manager. |
| `FHE16_GetLWESK`, `FHE16_GetLWESKLen` | Read LWE key pointer and length. | Low-level/debug surface only. |
| `FHE16_GetDecSK`, `FHE16_GetDecSKLen` | Read decryption key pointer and length. | Local decrypt key handle. |

## Encryption and Decryption

| Raw C symbol | Input | Output |
| --- | --- | --- |
| `FHE16_ENCInt` | `int64_t msg`, `int32_t bit` | Encrypted integer ciphertext. |
| `FHE16_ENCInt32` | `int32_t msg`, `int32_t bit` | WASM-friendly encrypted integer ciphertext. |
| `FHE16_ENCInt_Arr` | LSB-first bit array and width | Encrypted integer ciphertext. |
| `FHE16_ENC` | Single-bit message with explicit bit argument | Ciphertext pointer. |
| `FHE16_ENC_BIT` | Boolean bit using gate encoding | Boolean ciphertext pointer. |
| `FHE16_DECInt` | Ciphertext and secret key | `int64_t` plaintext. |
| `FHE16_DECIntVec` | Ciphertext and secret key | Allocated bit vector. |

## Arithmetic

| Raw C symbol | Public method | Notes |
| --- | --- | --- |
| `FHE16_ADD` | `add(a, b)` | Same-width integer addition. |
| `FHE16_ADD3` | `add3(a, b, c)` | Three-input addition. |
| `FHE16_SUB` | `sub(a, b)` | Same-width subtraction. |
| `FHE16_SMULL` | `mul(a, b)` | Signed n-bit product truncated to n bits. |
| `FHE16_FMULL` | `full_mul(a, b)` | Full n-by-n product returning 2n bits. |
| `FHE16_NEG` | `neg(a)` | Two's-complement negation. |
| `FHE16_ABS` | `abs(a)` | Signed absolute value. |
| `FHE16_RELU` | `relu(a)` | Selects zero for negative signed inputs. |
| `FHE16_ADD_POWTWO`, `FHE16_SUB_POWTWO` | `add_pow2`, `sub_pow2` | Optimized power-of-two adjustment. |

`FHE16_ADD_INTERLEAVED`, `FHE16_SUB_INTERLEAVED`, and `FHE16_SMULL_INTERLEAVED` are performance variants. Keep them out of the default high-level SDK until benchmark and scheduling behavior are documented.

## Bitwise and Selection

| Raw C symbol | Use |
| --- | --- |
| `FHE16_AND`, `FHE16_OR`, `FHE16_XOR` | Single-bit boolean ciphertext gates. |
| `FHE16_ANDVEC`, `FHE16_ORVEC`, `FHE16_XORVEC` | Integer/vector bitwise gates across ciphertext bits. |
| `FHE16_SELECT` | `selector ? a : b`; selector can be one bit or same-width vector. |

The browser worker currently uses `FHE16_ANDVEC`, `FHE16_ORVEC`, and `FHE16_XORVEC` for integer bitwise operations. High-level wrappers should expose that distinction instead of routing all bitwise calls through single-bit gates.

## Constant Operations

| Family | Raw C symbols |
| --- | --- |
| Constant multiply | `FHE16_SMULL_CONSTANT_Arr`, `_I64`, `_I32` |
| Full constant multiply | `FHE16_FMULL_CONSTANT_Arr`, `_I64`, `_I32` |
| Constant add | `FHE16_ADD_CONSTANT_Arr`, `_I64`, `_I32` |
| Constant subtract | `FHE16_SUB_CONSTANT_Arr`, `_I64`, `_I32` |
| Constant compare | `FHE16_LT_CONSTANT_*`, `FHE16_LE_CONSTANT_*`, `FHE16_GT_CONSTANT_*`, `FHE16_GE_CONSTANT_*` |

The `_Arr` form expects an LSB-first plaintext bit array. The `_I32` form is the first browser-friendly target; `_I64` should be used by native bindings when 64-bit FFI is reliable.

## Caller and Circuit Contract

Every method should be documented at method level, not only by family. The reference page tracks the caller, circuit path, and ownership rule for each exported symbol: [Method Reference](/sdk/method-reference).

| Method group | Primary caller | Circuit path to document |
| --- | --- | --- |
| Runtime/key methods | SDK context setup, browser worker init, benchmark harness | No homomorphic circuit; runtime allocation, key generation, or key loading. |
| Encryption/decryption | Key owner, local demo, authorized disclosure path | LWE encryption/decryption and bit encoding, not a homomorphic evaluation circuit. |
| Add/subtract | Product compute, SDK arithmetic | Parallel prefix adder through `FHE16_PREFIX_Templete` and `PrefixAdder_V2`. |
| Compare/select | Auctions, ranking, private conditionals | Prefix compare, equality reduction, NOT wrappers, and compare-select circuits. |
| Multiplication | Fixed-width arithmetic, scoring, product logic | DADDA partial-product reduction; full multiply returns 2n-bit output. |
| Bitwise | Boolean gates and integer bitwise operations | Single-bit `C_FHE16_*` gates or vector `GATE_VEC` path. |
| Constant operations | Browser worker constants, scoring weights, threshold filters | Plaintext bit-array path plus prefix, compare, or DADDA multiplier circuits. |
| Division/modulo | Advanced arithmetic | Shift-only fast paths, magic-multiplier constant division, or non-restoring encrypted division. |

## First Release Boundary

For the first public docs, treat context/key/encrypt/decrypt/add/sub/mul/compare/bitwise/select/constant ops/serialization as the supported surface. Keep debug methods, graph metadata, packing, compression, and interleaved variants in an advanced section until examples and tests are stable.
