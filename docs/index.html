A. FHE16 Paper Reviews

Each paper should be reviewed as technical evidence for the engine, not just listed as a publication.

FHE16

Fast, Compact and Hardware-Friendly Bootstrapping

Anchor paper for the low-latency FHE16 engine and the benchmark narrative around practical encrypted computation.

Arithmetic

Parallel Prefix FHE Arithmetic

Explains operation-level arithmetic design. This informs API methods such as add, lt, max, and select.

Correctness

Blind Rotation Error Analysis

Supports correctness, parameter, and reliability documentation for FHE16 profiles.

MPC

Actively Secure MPC

Supports SSFHE, threshold disclosure, and multi-party workflows beyond single-party encrypted computation.

C. FHE16 API

The first API direction is FFI-first: C is the ABI boundary, then Web Browser/WASM, Rust, and Python wrap the same method semantics.

Core

Common Methods

  • context_create, context_free
  • keygen, key import/export
  • encrypt_u16, decrypt_u16
  • add, lt, eq, max, select
Bindings

Web Browser, C, Rust, Python

The method names can be idiomatic per language, but behavior should map one-to-one to the same FFI method surface.
