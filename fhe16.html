FHE16

Device-free homomorphic execution engine

FHE16 is a deterministic 16-bit integer homomorphic execution spec designed to return the same result across browser, server, GPU, FPGA, and Python bindings.

FHE16 Runtime

A common engine for computing on encrypted values without decryption

FHE16 connects B2C demand, B2B risk, and blockchain confidential infrastructure through one execution model. Compatible implementations following the LibFHE16Python spec are designed to produce the same result for the same input.

A

Browser Runtime

Runs encrypted computation in the web browser, enabling privacy-preserving workflows from personal devices without installation. Coming soon.

B

Device-Free SDK

Starts with server builds and expands toward GPU around 2027 and FPGA around 2028. The target is consistent results across devices.

C

KeyMesh MPC

FHE16-based MPC key management coordinates disclosure or decryption only when threshold conditions are satisfied across participants.
