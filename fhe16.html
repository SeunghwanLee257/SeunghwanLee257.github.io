FHE16

Compute on encrypted data — without ever decrypting it.

FHE16 is a deterministic 16-bit fully homomorphic encryption runtime that returns identical results across browser, server, GPU, and FPGA. Bootstrapping in 2.89 ms. Raw data never leaves its owner.

Run it in your browser →Talk to the team

How it works

Software computes on the ciphertext. The plaintext is never seen.

FHE runs a program directly on encrypted values and returns an encrypted result — without ever decrypting them. No trusted hardware, no enclave to compromise. Security rests on standardized lattice cryptography you can audit, not a box you have to believe in.

A

Browser runtime

Run boolean, integer, and floating-point operations on encrypted data straight from the browser — no install, no server. Try it live: key generation in about 3 seconds, results bit-exact to plaintext.

Open the playground →

B

Deterministic server SDK

A 16-bit integer spec with no floating point, so browser, server, GPU, and FPGA return the identical result. Bootstrapping under 3 ms (ePrint 2024/1916).

C

MPC key layer

No single party holds the key. Threshold key custody and result release for B2B risk checks and confidential on-chain state. Actively secure in the dishonest-majority setting (CRYPTO 2025).
